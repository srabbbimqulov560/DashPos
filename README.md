# DashPos 🛒

A comprehensive B2B Point of Sale (POS) system for retail stores, featuring a robust cash management dashboard and a centralized super admin panel.

## 🚀 Live Demo
Check out the live working project here: **[DashPos on Firebase](https://dashpos-uz.web.app/)**

## ✨ Key Features
* **B2B POS System:** Tailored specifically for retail store daily operations and seamless management.
* **Cash Management Dashboard:** Robust tracking of sales, transactions, and real-time daily revenue.
* **Super Admin Panel:** Centralized control for managing stores, cashiers, and overall system settings.
* **Cloud Hosted:** Fast, secure, and reliable deployment using Firebase.

## 🛠️ Technologies Used
* **Frontend:** HTML5, CSS3, JavaScript (ES6+)
* **Backend & Hosting:** Firebase
